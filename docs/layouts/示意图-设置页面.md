# 设置页面布局设计

> 通过主页面顶栏「⚙️ 设置」进入，用于配置翻译服务；仅在首次使用时需要重点操作。

## 1. 整体布局

```text
┌──────────────────────────────────────────────┐
│  ← 返回                                设置  │  ← 顶栏 Header
├──────────────────────────────────────────────┤
│  API 地址                                    │
│    ┌────────────────────────────────────┐    │
│    │ https://api.deepseek.com           │    │
│    └────────────────────────────────────┘    │
│                                              │
│  API Key                                     │
│    ┌────────────────────────────────────┐    │
│    │ sk-••••••••••••••••（密码掩码）    │    │
│    └────────────────────────────────────┘    │
│    [ 👁 显示 ]                               │
│                                              │
│  默认模型                                    │
│    ┌────────────────────────────────────┐    │
│    │ deepseek-v4-flash            ▾     │    │
│    └────────────────────────────────────┘    │
│                                              │
│    ┌────────────────────────────────────┐    │
│    │              保存设置              │    │
│    └────────────────────────────────────┘    │
│                                              │
│  ⓘ API Key 仅保存在本地浏览器，仅随翻译      │
│    请求发送至对应服务。                      │
└──────────────────────────────────────────────┘
```

## 2. 模块说明

| 模块 | 元素 | 说明 |
| --- | --- | --- |
| 顶栏 Header | 「← 返回」+ 标题 | 返回主页面；未保存的改动需提示或放弃 |
| API 地址 | 文本输入框 | OpenAI 兼容端点地址，预填 `https://api.deepseek.com` |
| API Key | 密码输入框 + 显示切换 | 默认掩码显示，支持「显示/隐藏」 |
| 默认模型 | 下拉选择 | `deepseek-v4-flash`（默认）/ `deepseek-v4-pro` / `qwen` |
| 保存 | 主按钮 | 校验并写入 `chrome.storage.local`，成功后返回主页面 |
| 隐私说明 | 提示文案 | 说明 Key 仅存本地、仅随翻译请求发送 |

## 3. 交互规则

- **保存校验**：API Key 与 API 地址为必填项，为空时禁止保存并给出提示。
- **默认模型**：主页面操作区的模型快速切换与此处「默认模型」保持同步（改一处，另一处联动）。
- **返回行为**：有未保存改动时提示确认；无改动则直接返回主页面。
- **保存成功**：Toast/状态提示「已保存」，并自动回到主页面。

## 4. 状态与空态

| 场景 | 表现 |
| --- | --- |
| 首次使用（未配置 Key） | 主页面「一键翻译」触发时引导用户进入设置页填写 Key |
| 必填项为空 | 「保存」按钮禁用，输入框下方提示「必填」 |
| 保存失败 | 提示失败原因（如格式非法），停留在当前页，不丢弃输入 |
