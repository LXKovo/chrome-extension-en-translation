# 主页面（Popup）布局设计

> 插件的主要交互界面，通过点击工具栏图标打开。突出「一键翻译」与「下载」，保持简约。

## 1. 整体布局

```
┌──────────────────────────────────────────┐
│  文章翻译助手                      ⚙️ 设置  │  ← 顶栏 Header
├──────────────────────────────────────────┤
│  模型  [ deepseek-v4-flash       ▾ ]      │  ← 操作区 ActionBar
│                                            │
│  ┌────────────────────────────────────┐    │
│  │        🔄  一键翻译本文             │    │  ← 主操作（大按钮）
│  └────────────────────────────────────┘    │
│  ┌────────────────────────────────────┐    │
│  │        ⬇️  下载 Markdown            │    │  ← 次操作
│  └────────────────────────────────────┘    │
├──────────────────────────────────────────┤
│  ● 空闲 / 提取中… / 翻译中… / ✓ 完成 / ✗ 错误 │  ← 状态区 StatusBar
├──────────────────────────────────────────┤
│                                            │
│             结果展示区 ResultView           │  ← 可滚动
│                                            │
│   # 文章标题（中文）                        │
│   > 作者：xxx                              │
│   > 原文链接：https://…                    │
│                                            │
│   正文内容……（打字机逐字展示）              │
│                                            │
│                                            │
└──────────────────────────────────────────┘
```

- 弹窗尺寸建议：宽约 380px、高约 520px。
- 结果区占据主体高度并可独立滚动；顶栏与操作区固定。

## 2. 模块说明

### 2.1 顶栏 Header

- 左侧：插件名称「文章翻译助手」。
- 右侧：「⚙️ 设置」图标按钮，点击切换到设置页面。

### 2.2 操作区 ActionBar

| 元素 | 说明 |
| --- | --- |
| 模型选择下拉 | 快速切换模型（`deepseek-v4-flash` / `deepseek-v4-pro` / `qwen`） |
| 「一键翻译本文」 | 主操作，大尺寸高亮按钮；点击后执行「提取 → 翻译 → 展示」全流程 |
| 「下载 Markdown」 | 次操作；将当前结果导出为 `.md` 文件，无结果时置灰不可用 |

### 2.3 状态区 StatusBar

单行状态提示，随流程切换：

| 状态 | 提示文案 |
| --- | --- |
| 空闲 | 「点击上方按钮开始翻译」 |
| 提取中 | 「正在提取文章内容…」 |
| 翻译中 | 「正在翻译…」 |
| 完成 | 「✓ 翻译完成」 |
| 错误 | 「✗ 无法识别正文 / 网络错误 / 鉴权失败 / 额度不足」（可读错误） |

### 2.4 结果区 ResultView

- 使用 `md-wx` 的 `<MarkdownRenderer>` 渲染 Markdown。
- 翻译中：流式增量 → 逐字缓冲 → 动态更新渲染内容，实现打字机效果。
- 翻译中提供「停止」能力（点击后立即显示已生成内容）。
- 输出格式遵循需求文档：`# 标题` → `> 作者` / `> 原文链接` → 正文。

## 3. 状态与空态

### 3.1 首次使用（无结果）

```
┌──────────────────────────────────────────┐
│  文章翻译助手                      ⚙️ 设置  │
├──────────────────────────────────────────┤
│  模型  [ deepseek-v4-flash       ▾ ]      │
│  ┌────────────────────────────────────┐    │
│  │        🔄  一键翻译本文             │    │
│  └────────────────────────────────────┘    │
│  ┌────────────────────────────────────┐    │
│  │        ⬇️  下载 Markdown（禁用）     │    │
│  └────────────────────────────────────┘    │
├──────────────────────────────────────────┤
│  ● 点击上方按钮开始翻译                    │
├──────────────────────────────────────────┤
│                                            │
│          （空态提示区）                     │
│   将当前英文文章一键翻译为中文 Markdown     │
│                                            │
└──────────────────────────────────────────┘
```

### 3.2 打开时已存在上次结果

- 直接加载并展示 `lastResult`，状态区显示「上次翻译于 …」。
- 「下载」按钮恢复可用，用户可直接下载上次结果或点击「一键翻译」覆盖。

### 3.3 翻译中

- 结果区顶部先渲染标题 / 作者 / 原文链接，正文随后逐字打出。
- 状态区显示「正在翻译…」，操作区「一键翻译」转为「停止」或禁用，避免重复触发。

### 3.4 错误

- 状态区显示可读错误文案；结果区保留上次结果（若存在），不覆盖。
